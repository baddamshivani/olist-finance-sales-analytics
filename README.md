# Olist Finance & Sales Performance Analytics

An end-to-end Finance and Sales Performance Analytics project built using SQL Server and Power BI.

## Objective

Build an analytical system to evaluate sales performance, customer behavior, product performance, seller performance, payments, logistics, and customer experience.

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

The dataset is available through Kaggle.
